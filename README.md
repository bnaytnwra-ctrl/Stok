# بوت تنبيهات أخبار الأسهم الرخيصة (Penny Stocks News Bot)

بوت مجاني بالكامل يراقب أخبار الشركات الأمريكية منخفضة السعر (0.10$–4.00$)
عبر تلجرام، خلال نافذتين زمنيتين يوميًا (قبل الافتتاح وبعد الإغلاق)،
ويعمل تلقائيًا عبر GitHub Actions بدون أي سيرفر أو استضافة.

## الفكرة العامة
- GitHub Actions يشغّل السكربت مرة واحدة عند بداية كل نافذة تشغيل.
- السكربت يبقى يفحص الأخبار كل ~7 ثوانٍ حتى نهاية النافذة، ثم يتوقف تلقائيًا.
- كل خبر يمر عبر: فلتر كلمات مفتاحية (نظام نقاط) → استخراج رمز السهم →
  فلتر السعر → (اختياري) فلتر حجم التداول → إرسال تنبيه تلجرام + تسجيله.

## 1. إنشاء بوت تلجرام
1. افتح محادثة مع [@BotFather](https://t.me/BotFather) في تلجرام.
2. أرسل `/newbot` واتبع التعليمات لتسمية البوت.
3. احفظ الـ **Token** الذي يعطيك إياه (شكله مثل `123456:ABC-DEF...`).
4. أضف البوت إلى القناة/المجموعة التي تريد استقبال التنبيهات فيها، أو ابدأ
   محادثة خاصة معه مباشرة.
5. للحصول على `chat_id`:
   - أرسل أي رسالة للبوت (أو في القناة بعد إضافته كمشرف).
   - افتح المتصفح على:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
   - ابحث عن قيمة `"chat":{"id": ...}` في الرد.

## 2. الحصول على مفتاح Finnhub (مجاني)
1. أنشئ حسابًا مجانيًا على [finnhub.io](https://finnhub.io).
2. من لوحة التحكم، انسخ الـ **API Key**.
   - بدون هذا المفتاح سيعمل البوت لكن **فلتر السعر لن يعمل** ولن تصل
     أي تنبيهات (لأن الكود يرفض الخبر احترازيًا عند تعذّر التأكد من السعر).

## 3. رفع الكود إلى مستودعك
افترض أن مجلد المشروع اسمه `stock-news-bot` وأنك بداخله:

```bash
git init
git remote add origin https://github.com/bnaytnwra-ctrl/Stok.git
git add .
git commit -m "الإصدار الأول من بوت التنبيهات"
git branch -M main
git push -u origin main
```

> إذا كان المستودع فيه ملفات مبدئية (مثل README تلقائي من GitHub)، اسحبها
> أولًا: `git pull origin main --allow-unrelated-histories` قبل الـ push.

## 4. إضافة الأسرار (GitHub Secrets)
من صفحة المستودع في GitHub:
`Settings → Secrets and variables → Actions → New repository secret`

أضف الأسرار التالية:
| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `TELEGRAM_CHAT_ID` | معرّف المحادثة/القناة |
| `FINNHUB_API_KEY` | مفتاح Finnhub |

## 5. تعديل بريد SEC User-Agent (مهم)
افتح `src/config.py` وغيّر السطر:
```python
SEC_USER_AGENT = "StockNewsBot admin@example.com"
```
إلى بريدك الفعلي، لأن SEC EDGAR يرفض/يحظر الطلبات التي لا تحتوي بيانات
تواصل حقيقية في الـ User-Agent.

## 6. تفعيل الجدولة
الجدولة موجودة جاهزة في `.github/workflows/alert.yml` ولا تحتاج تعديل إلا
إذا رغبت بتغيير الأوقات. GitHub لا يفعّل أحيانًا الـ scheduled workflows في
مستودع جديد إلا بعد أول push يحتوي الملف على فرع `main` — تأكد أن الفرع
الافتراضي فعلاً `main`.

## 7. اختبار يدوي قبل الاعتماد على الجدولة
من تبويب **Actions** في GitHub، اختر workflow "Stock News Alert Bot" ثم
اضغط **Run workflow** (متاح بسبب `workflow_dispatch` في الملف) لتجربته
فورًا دون انتظار الموعد المجدول.

## 8. مراجعة السجلات
- `logs/alerts_log.csv`: كل تنبيه أُرسل فعليًا (الوقت، الرمز، العنوان،
  السعر، المصدر، الرابط، نقاط التقييم).
- `logs/seen_ids.json`: معرّفات الأخبار التي عولجت مسبقًا (لمنع التكرار)،
  يُحتفظ بها 14 يومًا فقط ثم تُحذف تلقائيًا (`SEEN_IDS_RETENTION_DAYS`
  في `config.py`).
- كلا الملفين يُحدَّثان تلقائيًا عبر commit/push في نهاية كل تشغيلة
  (خطوة "Commit and push updated logs" في الـ workflow).

## 9. تحسين الفلاتر لاحقًا
- عدّل `POSITIVE_KEYWORDS` و`NEGATIVE_KEYWORDS` و`POSITIVE_SCORE_THRESHOLD`
  في `src/config.py` بناءً على مراجعتك لـ `alerts_log.csv` بعد فترة تجريبية.
- فلتر حجم التداول موجود في `src/volume_filter.py` لكنه معطّل افتراضيًا
  (`ENABLE_VOLUME_SPIKE_FILTER = False`) — فعّله بعد التأكد من استقرار
  البوت بدونه أولًا.

## قيود معروفة (مقصودة ومقبولة من التصميم)
- المصادر المجانية فيها تأخير طبيعي (ثوانٍ إلى دقائق) مقارنة بالخدمات
  المدفوعة الاحترافية.
- `cron` في GitHub Actions لا يضمن دقة الثانية وقد يتأخر بضع دقائق وقت
  الازدحام.
- هذا المشروع أداة تنبيه إخباري فقط، وليس نصيحة استثمارية أو ضمان ربح.
